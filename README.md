# Bellas Artes Lab — GitHub Pages

Paquete listo para publicar en **GitHub Pages** con soporte HTTPS automático para activar el micrófono en vivo, el sonar acústico y la grabación en iPad, iPhone o escritorio.

## Cómo subirlo en 3 pasos

1. Crea un repositorio nuevo (público) en GitHub, por ejemplo `bellas-artes-lab`.
2. Sube los archivos descomprimidos (`index.html`, `.nojekyll` y `README.md`) a la raíz de la rama `main`.
3. Entra a **Settings → Pages**, selecciona **Deploy from a branch**, elige `main` y `/ (root)`, y guarda. En 1–2 minutos tendrás tu enlace `https://<tu-usuario>.github.io/<tu-repo>/`.
